# 论文seeker

输入「大学名称」和「专业 / 领域」，即可检索该机构研究人员的 **论文** 与 **综述**，提供原文链接，并可一键导出 **Word 文档**。

数据来源：[OpenAlex](https://openalex.org)（免费、CC0 授权的学术数据库，无需 API Key）。

## 两种使用方式

### 方式一：单文件网页版（推荐，无需安装）

直接**双击打开 `论文查询.html`** 即可使用，无需 Node、无需安装依赖、无需命令行。

- 纯前端运行，直接在浏览器里调用 OpenAlex 检索并生成 Word 文档
- 生成的是真正的 `.docx`；若 Word 库加载失败会自动降级为 `.doc`（Word/WPS 均可打开）
- 需要联网（用于访问 OpenAlex 与加载 Word 生成库）

### 方式二：服务器版（一键启动）

双击 **`启动.bat`**（首次会自动安装依赖），或手动：

```bash
npm install --cache ./.npm-cache   # 首次安装依赖
npm start                           # 启动后访问 http://localhost:3000
```

> 说明：单文件版与服务器版功能一致，任选其一即可。

## 功能

- 🏛 支持中英文大学名称（如「清华大学」「Tsinghua University」）
- 🔬 支持中英文领域（内置 60+ 常用中文领域词典，也可直接输入英文术语）
- 👨‍🏫 自动识别该机构在该领域的主要研究人员（按发文量与被引排序）
- 📄 每位研究人员分别列出其「论文」与「综述」（综述用 `type:review` 精确过滤）
- 📑 独立的「领域代表性综述」板块，直接呈现被引最高的综述文章
- 🔗 每条文献提供 DOI、PDF、开放获取页、OpenAlex 页链接
- 📥 一键导出 Word（.docx）文档（支持导出全部 / 单个教授）

## 快速开始

环境要求：Node.js ≥ 18（推荐 20+）。

```bash
# 1. 安装依赖（如遇到 npm 缓存目录权限问题，用 --cache 指定工作区内目录）
npm install --cache ./.npm-cache

# 2. 启动
npm start
```

打开浏览器访问：**http://localhost:3000**

## 使用方式

1. 输入大学名称，例如：`清华大学` 或 `Tsinghua University`
2. 输入专业/领域，例如：`机器学习` 或 `Machine learning`（可从下拉建议中选择）
3. 点击「查询」，等待 5–20 秒（需向 OpenAlex 发起多次检索）
4. 查看结果：
   - 顶部「领域代表性综述」列出该机构该领域被引最高的综述
   - 下方每位研究人员卡片内，可切换「论文 / 综述」标签页
   - 每条文献下方有 DOI / PDF / 开放获取页 链接按钮
5. 点击「导出全部 Word」或某教授卡片上的「导出此教授 Word」下载 .docx

## 接口说明

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/fields` | 返回内置领域词典（中文→英文） |
| GET | `/api/search?field=…&university=…` | 查询研究人员及其论文/综述 |
| POST | `/api/export-word` | 传入查询结果 JSON，返回 .docx 文件 |

## 说明与限制

- 结果基于 OpenAlex 的公开数据，按被引量排序；「综述」指 OpenAlex 中 `type=review` 的文献（文献综述/调查类文章）。
- 领域建议优先使用英文或内置中文词典；OpenAlex 对中文概念检索支持有限。
- 研究人员识别基于「该机构 + 该领域」的高被引文献的作者署名，不区分职称；结果仅供参考，引用前请核对原始文献。
- 默认端口 3000，可用环境变量 `PORT` 修改。
